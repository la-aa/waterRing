# waterRing

A small Electron desktop assistant that reminds you to drink water.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run dist:win
```

## Features

- Tray resident app
- Cute cat-themed reminder window
- Drink now / snooze actions
- Local settings persistence
- Windows auto-start support

## Assets

The app uses `ico/myCat_ico.jpg` as the current pet image source. Replace that file to change the look later.
